# Экран-помощник (версия 3)

Показываете снимок непонятного экрана — получаете объяснение простыми словами и пошаговое сопровождение
с подсветкой нужной кнопки. Подходит детям, подросткам, взрослым и пожилым: тон, размер текста, примеры и
предупреждения подстраиваются под профиль и интересы.

## Запуск
- **Сайт:** `cd app && python3 -m http.server 8080` → http://localhost:8080 (на Windows `python`).
- **Приложение:** `npm install && npm start`; установщик — `npm run build`.
- При первом запуске выберите профиль, интересы и режим. Без ключа всё считается прямо на устройстве.

## Подключение умного ИИ (бесплатно)
1. https://aistudio.google.com/apikey → Create API key.
2. ⚙ → «Приватность и ИИ» → вставьте ключ → **«Проверить ключ»**. Приложение само подберёт рабочую модель.

### Если ИИ «не работает»
Главная причина в версии 2: модель gemini-2.5-flash была отключена Google 16.10.2026. Теперь приложение
перебирает актуальные модели (gemini-flash-latest, 3.5-flash, …) и показывает настоящую причину сбоя
(неверный ключ, лимит, нет связи) с блоком «Подробности для помощника».

## Приватность
- Режим «только на моём устройстве»: ничего не отправляется (первый раз скачивается модуль распознавания текста).
- На бесплатном тарифе Gemini Google может использовать присланное для улучшения сервисов и читать запросы
  (если подключён платёжный аккаунт Cloud Billing — условия другие). Поэтому: автоскрытие номеров, почт, паролей,
  ручная закраска, согласие перед первой отправкой, кнопка «Что отправляется?».
- Ключ — только на устройстве (можно «до закрытия вкладки»). История и снимки отключаются, есть «Стереть всё»,
  PIN на настройки (защита от случайных изменений, не от взлома).

## Профили и настройки
Ребёнок / Подросток / Взрослый / Старше 60: свой тон, правила безопасности и рекомендуемый вид. Настраиваются:
6 тем, цвет интерфейса и подсветки, 5 шрифтов, размер текста, интервалы, углы, размер кнопок, анимация, ширина,
язык ответов, простота объяснений, число шагов, голос, кого звать на помощь.
